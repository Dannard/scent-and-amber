# Scent and Amber

Scent and Amber is a premium fragrance e-commerce concept website designed to showcase product presentation, brand storytelling, and a clean purchase flow.

The project focuses on making scent products feel desirable while keeping information clear and easy to evaluate, especially on mobile.

## Live Links

- Live Site: [https://scent-and-amber.vercel.app](https://scent-and-amber.vercel.app)
- Repository: [https://github.com/Dannard/scent-and-amber](https://github.com/Dannard/scent-and-amber)

## What This Project Demonstrates

- Premium visual direction (dark-first with optional light mode)
- Product-first merchandising and scent note storytelling
- Responsive e-commerce page structure
- Variant selection and persistent cart behavior
- Multi-step checkout UI with form validation
- Reusable UI/component architecture in Next.js

## Key Pages

- Home
- Shop
- Product Detail
- Collections
- Brand Story
- Cart
- Checkout (UI flow)
- FAQ

## Tech Stack

- Next.js 16 (App Router)
- React 19
- TypeScript
- Tailwind CSS v4
- Vitest + Testing Library

## Local Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build and Test

```bash
npm run lint
npm test
npm run build
```

## Notes

- This is a frontend-focused implementation.
- Checkout is a production-style UI flow and does not process real payments.
- No backend API keys or third-party secrets are required to run locally.
